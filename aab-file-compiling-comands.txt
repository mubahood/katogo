APP 1 — LugaFlix  (current: 6.0.56+657)
Path: /Users/mac/Desktop/github/lugaflix
────────────────────────────────────────────────────────────────────────────────

Build a new release AAB for the LugaFlix app.

Steps to follow IN ORDER:
1. Open /Users/mac/Desktop/github/lugaflix/pubspec.yaml
2. Find the line that starts with "version:" (e.g. version: 6.0.56+657)
3. Increment BOTH the semantic version and the build number by 1
   — example: 6.0.56+657  →  6.0.57+658
4. Save pubspec.yaml
5. cd into /Users/mac/Desktop/github/lugaflix
6. Run: flutter build appbundle --release
7. Wait for the build to complete successfully (do NOT proceed on error)
8. The output file will be at:
   /Users/mac/Desktop/github/lugaflix/build/app/outputs/bundle/release/app-release.aab
9. Open that folder in Finder so the AAB file is ready to upload to Play Console

Do NOT build the TV variant. This is the standard mobile build only.
Report the new version number and confirm the AAB file path when done.
